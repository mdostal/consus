Consus

The architect tool
for any repo.

A local knowledgebase, graph, and doc editor for your repo's decisions, docs, and architecture — with an agent-facing API so any harness can read and write to it.

View on GitHub Quickstart ↓

Index. Open. Interact. Propose.

Index

An on-demand scan walks a repo's .pHive/ planning tree and populates a local SQLite doc index. Deliberate, never a background poll.

Open

The per-project view brings together the diagram cascade, architecture diagram, docs, and KB entries — everything a project has decided, in one place.

Interact

Read and edit docs in place. Drag, relabel, and rewire diagrams on a live React Flow canvas with a running changeset of what's pending.

Propose

"Fire to harness" sends a {diff, description} to whatever local harness is configured. It applies the change and reports back.

A repo accumulates decisions, briefs, PRDs, and architecture docs as files on disk. Reading them cleanly from a shell session, or tracking which decisions are still open, is tedious. Consus gives that planning tree a real interactive surface — without coupling to any external system.
