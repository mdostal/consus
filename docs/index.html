What Consus does

Consus is the readable surface for Pantheon's ideation, planning, question, and sign-off process.

  • Renders generated planning artifacts.
  • Surfaces human decisions and parked questions.
  • Preserves approved context as knowledgebase state.
  • Connects the review loop to Pantheon build lanes.

Adapters feed a durable review surface.

Quickstart

Run Consus locally.

The app uses a Vite web UI, Fastify server, and SQLite persistence. Node.js 24.x is the supported runtime.

npm ci npm run dev npm run build npm test

Role in Pantheon

The human review point between planning and build.

Minerva

Supplies surveys, plans, and parked questions that need a human answer.

Multica

Provides issue state, comments, assignment, and workflow coordination.

Auriga

Consumes approved work once the decision loop has produced a buildable story.

Consus

Renders the evidence, captures the answer, and keeps the accepted context readable.
